<a id="get-started"></a>
## Pierwsze kroki

Zainstaluj, korzystając z powyższych opcji. Następnie otwórz **Klonowanie głosu**, wybierz głos lub dodaj czyste nagranie referencyjne, wpisz tekst i wygeneruj. Aplikacja pyta przed pobraniem dowolnego modelu.

<details>
<summary><strong>Więcej opcji instalacji</strong>: konkretna wersja, aktualna wersja główna, odinstaluj, ze źródła, za pomocą agenta kodującego</summary>

```powershell
irm https://voicestudio.sh/install.ps1 | iex
```


**Ze źródła**

```bash
git clone https://github.com/debpalash/VoiceStudio.git
cd VoiceStudio
bun run dev
```

`bun run dev` instaluje zależności JavaScript i, w przypadku korzystania z obsługiwanego lokalnego backendu, zależności Pythona przed uruchomieniem Electrona. Uruchom `bun run setup:api` bezpośrednio, gdy potrzebujesz jedynie odbudować środowisko Pythona.

Zobacz [Konfiguracja elektronów](../../electron/README.md).

**Za pomocą środka kodującego** (Claude Code, Codex, Cursor,…) wklej:

```text
Install the VoiceStudio app on this device and verify it works, following
https://github.com/debpalash/VoiceStudio/blob/main/docs/install/agent.md
```

Aktualizujesz wersję 0.5.3 lub starszą (aplikacja Tauri)? [Zainstaluj nową aplikację osobno](../../docs/electron-migration.md).

</details>
