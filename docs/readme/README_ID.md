<a id="get-started"></a>
## Mulai

Instal menggunakan opsi di atas. Kemudian buka **Kloning suara**, pilih suara atau tambahkan rekaman referensi yang bersih, ketik teks Anda dan buat. Aplikasi ini bertanya sebelum mengunduh model apa pun.

<details>
<summary><strong>Opsi pemasangan lainnya</strong>: versi tertentu, versi utama saat ini, uninstall, dari sumber, dengan agen pengkodean</summary>

```powershell
irm https://voicestudio.sh/install.ps1 | iex
```


**Dari sumber**

```bash
git clone https://github.com/debpalash/VoiceStudio.git
cd VoiceStudio
bun run dev
```

`bun run dev` menginstal dependensi JavaScript dan, saat menggunakan backend lokal yang didukung, dependensi Python sebelum meluncurkan Electron. Jalankan `bun run setup:api` secara langsung ketika Anda hanya perlu membangun kembali lingkungan Python.

Lihat [Pengaturan elektron](../../electron/README.md).

**Dengan agen pengkodean** (Claude Code, Codex, Cursor, …), tempel:

```text
Install the VoiceStudio app on this device and verify it works, following
https://github.com/debpalash/VoiceStudio/blob/main/docs/install/agent.md
```

Mengupgrade dari 0.5.3 atau lebih lama (aplikasi Tauri)? [Instal aplikasi baru secara terpisah](../../docs/electron-migration.md).

</details>
